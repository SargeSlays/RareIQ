Drop reference card images in this folder.

For each image, add a JSON file with the same filename.

Example:
  venusaur_142_204.jpg
  venusaur_142_204.json

Example JSON:
{
  "id": "jp-set-142-204",
  "name": "Venusaur",
  "printed_name": "フシギバナ",
  "collector_number": "142/204",
  "language": "Japanese",
  "set_name": "Example Set",
  "rarity": "Rare"
}

Then click REBUILD INDEX in the RareIQ dashboard.
