# Rare IQ Brand System v1.0

This directory contains the production subset of the approved Rare IQ "Signal Cut" identity used by Studio X.

## Source

- Package: `Rare-IQ-Brand-System-v1.0`
- Standards: `Rare-IQ-Brand-Standards-v1.0.pdf`
- Approved: August 2026

## Product assets

- `logos/rare-iq-primary-dark.svg` - primary horizontal lockup on Obsidian
- `logos/rare-iq-primary-light.svg` - primary horizontal lockup on Warm Ivory
- `logos/rare-iq-icon-dark.svg` - application symbol on Obsidian
- `logos/rare-iq-icon-light.svg` - application symbol on Warm Ivory
- `rare-iq-tokens.css` - official developer color, radius, and spacing tokens

The SVG files are production masters. Do not redraw them, animate them, add effects, or alter the mint/amber relationship.

## Product rules

- Use the horizontal lockup by default.
- Use Signal Mint on Obsidian whenever possible.
- Use Discovery Amber only for verified discovery, warning, or review moments.
- Use Arial for interface copy and Consolas where monospaced data improves comprehension.
- Prefer sentence case, quiet surfaces, precise borders, and honest collectible imagery.
- Do not introduce cyan-purple gradients, logo glow, chrome, bevels, or cyberpunk effects.

Studio X loads `rareiq_brand_v1.css` after all legacy component styles. That final layer maps existing component contracts to the official dark and light systems without changing product behavior.
