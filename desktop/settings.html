Advanced encoding

Audio uses 48 kHz stereo. Encoder availability is checked when starting; a GPU name alone does not confirm encoding works.

Live and Twitch VOD audio

Guest soundboards and voice effects arrive mixed with the guest microphone; selecting that microphone includes those sounds. Audio inside nested browser sources is currently excluded.

Separate VOD mix is local; Twitch platform acceptance is pending. Other destinations receive the Live mix.

Live includes every source by default. The VOD mix includes voices and leaves out screens, videos and cues unless selected below. Default rows apply to each category; source rows override them.

Levels are saved profile settings: 0 dB is unity, negative values reduce sound and positive values boost it. Save and prepare output to apply new levels; these controls do not change the running mix.
