## Status and demo legend

- **`locally_verified`** — Existing implementation with recorded local acceptance; only the explicitly recorded layer is established.
- **`implemented_partial`** — Working code covers a narrower workflow; the row limitation is part of its status.
- **`external_obs_only`** — Available through separately configured OBS; not a native Producer feature or full OBS remote editor.
- **`missing`** — No comparable supported native Producer workflow established in the inspected implementation.
- **`setup_pending`** — Implementation exists, but provider setup, permissions, identity or external acceptance prevents the corresponding live claim.
- **`implementation_in_progress`** — Active source work in this phase; not completed, packaged, accepted or demo-ready by this report.

Safe local demonstration uses accepted local media, Preview/Take, settings and explicitly isolated Rehearsal within existing authorization. Provider setup/drafts are setup-only. Missing/in-progress rows are not ready claims. External OBS must be named as the separately configured encoder. A status is neither fresh runtime certification nor permission to perform an action.

Priority: P0 = current demo slice; P1 = core workflow/claim boundary; P2 = subsequent capability; P3 = optional ecosystem expansion.

## Today: three creator workflows

**Gameplay:** Scene Preview/Take, generated producer-screen pixels, Live/VOD mix controls and native MKV recording have local acceptance. Remaining: Physical game/window selection and audio still need operator testing; native game hooks, global hotkeys and full Program replay remain missing.

**Podcast/interview:** Invited guest/waiting-room/backstage-chat and generated-media mix-minus workflows; native one-mix MKV recording has actual bundled acceptance. Remaining: Physical headphone listening/echo, isolated guest stems, six-track recording and StackThis producer identity remain separate.

**General production:** Images/video, bounded titles, smart layouts, reviewed HTTPS visual sources, native Program MKV recording and output settings/statistics are locally exercised at the recorded layers. Remaining: Free geometry/groups/filter rack, dual native canvas, provider permissions and real platform receipt remain separate. Main-profile promotion is not claimed.

## Reading the comparison

OBS entries identify native first-party facilities separately from plugins/services. Streamlabs entries identify Free Desktop, Ultra/Ultra+ and companion services. Cloudbot, tipping, merch, cloud storage and Multistream rely on hosted services; Video Editor/Cross Clip/Mobile/G HUB Replay are separate applications/services. Their presence in a subscription suite is not proof that every feature is native to the Desktop editor.

Free Streamlabs Desktop permits one landscape and one portrait destination simultaneously. Ultra Multistream uses cloud fan-out; Producer sharing a local encoder does not eliminate per-destination upload. Current Streamlabs storage is 1 / 10 / 30 GB across Free / Ultra / Ultra+; historic unlimited backup claims are not current entitlements.

Repository evidence paths are relative to the checkout. A test path points to a relevant guard; it does not claim that the audit reran that test.
